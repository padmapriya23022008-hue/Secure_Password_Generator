# Password Generator 🔐

A simple Python Password Generator application that creates strong and random passwords based on user-defined length.

## Tools Used

* Python

## Features

* Generate Random Passwords
* User Input for Password Length
* Strong Password Creation
* Simple Command-Line Interface

## Objective

To build a Password Generator application using Python concepts like random module, strings, loops, and user input handling.

## Conclusion

This project helps users generate secure passwords easily while improving practical Python programming and logical thinking skills.
